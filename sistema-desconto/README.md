# 📈 Sistema de Desconto Progressivo
 
Script em Python que calcula o desconto de uma compra conforme o valor informado pelo usuário, seguindo uma tabela de descontos progressivos.

---

### 📋 Como funciona
 
O programa solicita o valor da compra e aplica um percentual de desconto com base na seguinte regra:
 
💰 Valor da compra | 🏷️ Desconto aplicado
-|-
Menor que R$ 200,00 | 5%
Entre R$ 200,00 e R$ 299,99 | 10%
A partir de R$ 300,00 | 15%

---

### 💻 Ao final, o script exibe:
- O percentual de desconto aplicado
- O valor do desconto em reais
- O valor final a pagar
